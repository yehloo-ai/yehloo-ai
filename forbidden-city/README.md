# 故宫 · 内外之间

[打开独立公开网页](https://yehloo-ai.github.io/yehloo-ai/forbidden-city/)

可旋转、缩放的故宫三维结构示意，包含宫城总览、15 座具名建筑和 66 个部位入口。进入具体宫殿后，可以查看内部柱网、梁架、陈设和装饰；部分建筑提供周边院落与配殿视图。

## 操作

- 拖动旋转、滚轮缩放，也可使用画面上的旋转和放大缩小按钮。
- 360 度自动旋转、屋顶抬升、剖开查看、室内近看、梁架结构和柱网平面。
- 点击部位按钮，定位塑像、宝座、帘幔或庭院器物。

## 本地运行

此目录已包含全部运行依赖，无需 npm。进入本目录后运行：

```sh
python3 -m http.server 8769
```

打开 http://127.0.0.1:8769/ 。请通过 HTTP 服务打开，避免 file:// 下总览与室内视图通信受限。

## 资料与精度

模型依据故宫博物院公开材料制作，是交互式解释性重建，并非官方模型或测绘、扫描复原。雕塑形貌、尺度、纹饰和部分院落间距有简化或推定；附属建筑内部未作专项复原。参考与具体范围见 [资料说明](资料说明.md)。
