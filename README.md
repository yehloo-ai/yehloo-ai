## ⭐ Selected work

**🗂️ [Yeyu](https://github.com/yehloo-ai/yeyu)**
An open-source Chrome workspace for returning to useful webpages and keeping up with new content. Screenshot cards make destinations recognizable, live drag-and-drop supports personal organization, and update badges bring changes into view. It explores how visual memory and lightweight change awareness can make everyday navigation feel more direct.

**📸 [DreamFrame](https://github.com/yehloo-ai/DreamFrame)**
A mobile-first AI co-photo MVP that turns a user portrait, a selected person, and a contextual scene into one natural-looking shared photograph. It explores identity preservation, multi-image conditioning, privacy consent, generation controls, and provider switching as a responsible synthetic-media experience.

**🗞️ [AI News Station](https://github.com/yehloo-ai/ai-news-station)**
An AI intelligence hub for teams: daily digests, model and funding timelines, a tools directory, and a cross-filterable news stream. More than a content page, it explores how an AI design organization builds shared awareness and turns external change into internal action.

**🔍 [Patent Scout](https://github.com/yehloo-ai/lingan-tanzhen)**
A patent-feasibility workflow for early product ideas. It translates complex search evidence into innovation scores, product directions, risks, and interface flows. The hosted version is a no-cost functional demo; the local FastAPI implementation is retained in the repository.

**📚 [College of Design](https://github.com/yehloo-ai/college-of-design)**
A curated learning system for designers growing in the AI era, organized around UX foundations, AI workflow integration, and career development. It brings together original articles, audio transcripts, and a 17-step Vibe Coding guide as a reusable capability-building platform across desktop and mobile.

**🎙️ [AI Daily Note](https://github.com/yehloo-ai/ai-daily-note)**
A cross-device voice-to-Obsidian workflow that reduces the distance between a thought and a reusable team or personal knowledge asset. It captures, cleans, structures, and routes spoken ideas into durable notes, exploring how lightweight AI automation can support reflection, team learning, and long-term knowledge compounding.

**🎬 [WanHuaTong](https://github.com/yehloo-ai/wanhuatong)**
An automated text-to-video pipeline that turns lesson content into storyboards, generated imagery, voice, and animation. It connects content parsing, visual planning, narration, and motion into a repeatable production workflow, showing how a small team can turn educational material into publishable media with fewer handoffs.

## 🛠️ How I lead and build

My working loop is:

1. Frame the user and business decision, not just the interface request
2. Map the human-AI workflow, including uncertainty and failure states
3. Build a working prototype early with coding agents
4. Evaluate usefulness, controllability, trust, and delivery cost
5. Turn the learning into reusable patterns, standards, and team capability
